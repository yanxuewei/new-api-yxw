# P1「电话」告警通道 · 实测与选型（2026-10-19）

> 背景：任务 32 卡要求「P1（站点不可用等）→ **电话** + 群 + 短信，5 分钟响应」，
> 并预设「云监控告警规则绑定联系人组并勾选电话通道」。
> 结论：**该设计在国际站不可实现**，需改道；本文件是取证与三个候选方案的对比。

## 一、实测证据

1. **`aliyun cms PutContact` 参数元数据（CLI 3.5.1 自带文档）**：

```
--Channels.AliIM        <props="china">…phone number, email address, DingTalk chatbot, or TradeManager.</props>
                        <props="intl">Specify at least one of the following contact methods:
                                       email address or DingTalk chatbot.</props>
--Channels.Mail         …
--Channels.DingWebHook  … <props="intl">email address or DingTalk chatbot.</props>
```

⇒ 国际站联系人**只有 邮箱 / 钉钉机器人** 两种渠道；**没有 phone、没有 SMS**。
（参数列表里根本没有 `Channels.SMS` / `Channels.Phone`，不是“有但没开通”。）

2. **现状盘点（同批实测）**：

| 项 | 实测值 |
|---|---|
| `cms DescribeContactList` | **0 条** |
| `cms DescribeContactGroupList` | **0 组** |
| `cms DescribeMetricRuleList` | **0 条** |
| `cms DescribeSiteMonitorList` | 1 条（`likha-hk-newapi-status`，TaskState=1 ✅） |
| SLS 告警 | 5 条（canary 2 + 本卡燃烧率 3），**全部无行动策略** |

⇒ 卡片「前置：云监控联系人/联系人组已建」不成立；P1 链路是从零开始，且缺的关键件（电话）在平台侧就不存在。

## 二、三个候选

### A. 钉钉群 + 云监控邮件（0 成本，但不满足 P1）

- 做法：云监控联系人 = 钉钉 webhook + 邮箱；SLS 告警行动策略 = 钉钉。
- 满足：P2/P3 的「群」通知、留痕。
- 缺：**无语音呼叫**，夜间 P1 依赖人盯群 ⇒ 卡片坑 1（“告警用邮箱/群，夜间无人响应”）原样复发。
- 结论：**只能作为 P2/P3 的底座**，不能顶 P1。

### B. 第三方 on-call（推荐）

- 做法：SLS 告警 / 云监控 → **webhook** → on-call 平台（PagerDuty、Better Stack、UptimeRobot 等）
  → 语音呼叫 → 未接则按升级链（第二值班 → 负责人）。
- 满足：真电话、升级链、ack 状态、事故时间线（比自建更省事）。
- 成本：$0（免费档通常 1 人/少量告警）~ $30/月。
- 落地：一个 webhook URL + 值班人手机号（平台侧填，不入仓库）；我们只需在 SLS 告警行动策略里填 URL。
- 风险：数据出境（告警内容含 host/错误率，不含业务数据）；账号需负责人注册。

### C. 自建 webhook 中转

- 做法：ops 节点（`c2i.large`，包月）跑一个小服务：收 webhook → 调语音 API → 记录 ack。
- 满足：全自持、无第三方。
- 成本：语音 API 费用 + 维护（要处理重试、去重、HA —— 本身成了业务）。
- 风险：**告警链路自己挂了没人知道**（与卡片坑 3「把 Prometheus 当唯一告警源」同源）。
- 结论：不建议，除非有合规硬约束禁止第三方。

## 三、建议

1. **P2/P3 立刻可用（0 成本）**：先建钉钉群机器人 + 云监控联系人（邮箱/钉钉），把 5 条 SLS 规则接上行动策略。
2. **P1 走 B**：负责人选一家 on-call（建议先试免费档），提供 webhook → 我把 SLS 行动策略 + 云监控 webhook 接好并做 V1 触发实测。
3. **在 §12 SLA 口径里登记**：P1 通道 = 第三方语音呼叫（非云监控电话），避免对外承诺与实现不符。
4. **演练**：优先在 `newapi-dev`（雅加达 dev）演练（不碰生产）；生产演练（`new-api-stable` 缩 0）需单独授权。
