# 场景矩阵 —— impl_tech.md §3.9 落地

对象：`new-api` 中继主链路与管理面。目标值见 `impl_tech.md §1.3`，场景定义见 §3.9。
执行器沿用 `deploy/perf/k6/run.sh`（云助手 → 集群内 k6 Job），不另建一套。

## 目录（本目录内）

| 路径 | 作用 |
|---|---|
| `k6/relay-chat.js` | S1 非流式 / S2 流式中继压测（开环或闭环由 `EXECUTOR` 自动推断） |
| `k6/s4_admin.js` | S3 管理面列表（渠道列表 + 日志分页，PageSize=100；setup 内登录拿 JWT） |

| `baseline/README.md` | 基线归档与回归门禁（劣化 > 10% 阻断） |
| `baseline/2026-10-30-e40314f52.md` | 首次执行报告（S1/S2/S4 完成，S3/S5/S6 未完成） |

执行器本体（`k6/run.sh`、`k6/sse.js`、`k6/bodies/`、`k6/report.py`）见 `k6/README.md`。

## 工具与分工

- **k6**：场景编排（SSE、开环到达率、并发保持），在集群内 Job 执行。
- **vegeta**：常量 QPS 交叉验证（同一 target 用两种工具跑，排除工具自身偏差）。
- **hey**：冒烟；本仓以 k6 单档冒烟替代。

## 运行方式

脚本通过 `run.sh` 的 `K6JS_FILE` 覆盖接入（`run_body` 会统一纠正各动作体内的默认赋值）：

```bash
# S1 非流式：1600 rps（2 副本 × 800/实例），mock 需 128 token 且首字延迟归零
K6JS_FILE=$PWD/deploy/perf/k6/relay-chat.js \
bash deploy/perf/k6/run.sh arrival perf-new-api-slave 1600 120s 8 2

# S2 流式：恒并发（1500 并发/实例 → 2 副本 3000），mock 需 1000 chunk / 2s
K6JS_FILE=$PWD/deploy/perf/k6/relay-chat.js \
bash deploy/perf/k6/run.sh shard 3000 120s 6

# S3 管理面：800 QPS/实例（需要可用的 admin 凭据）
K6JS_FILE=$PWD/deploy/perf/k6/s4_admin.js \
bash deploy/perf/k6/run.sh arrival perf-new-api-slave 1600 120s 8 2
```

> `run.sh` 会把选定脚本装成 ConfigMap 里的 `sse.js` 并挂到 `/scripts`，因此**文件名不影响执行**，只由 `K6JS_FILE` 决定内容。执行后看首行 `下发脚本 ConfigMap：k6-sse-<hash>`，hash 变化即说明换脚本成功。

## 场景矩阵与判据

| 场景 | 目标 | 判据 |
|---|---|---|
| S1 非流式 chat | ≥ 800 QPS/实例，P99 ≤ 80 ms（网关内） | `relay_success`、`relay_ttft_ms` p99（mock 首字延迟须为 0） |
| S2 流式 chat | ≥ 1,500 并发 SSE/实例，内存 ≤ 1.5 GiB | 并发数、`mem_peak_mi`、完整流率 |
| S3 管理面列表 | ≥ 800 QPS | `admin_success`、`admin_latency_ms` |
| S4 上游故障注入 | 输出「重试放大比」 | 注入 5% 5xx 下的端到端成功率 ÷ 上游成功率（需 `RETRY_TIMES>0` 才有放大） |
| S5 限流命中 | 429 + `Retry-After` | 需先配 `GLOBAL_API_RATE_LIMIT` 并滚动重启 |
| S6 长任务 | `system_task_locks` 租约不被多实例抢占 | 需先造 10k 未完成任务 |

## 环境前提（与 §3.9 一致）

- 客户端与被测跨可用区、同 VPC；mock 上游在集群内（`mock-upstream`，6 副本）。
- 必须开启 `BATCH_UPDATE_ENABLED=true`、`MEMORY_CACHE_ENABLED=true`。
- 禁用真实上游，避免计费噪声。
- **mock 参数是全局的**：跑完 S4 必须把 `ERROR_RATE` 回滚为 0，否则后续全部带错误。
