### 三个新发现的坑

1. **PATH 被 Windows 污染**：`/etc/wsl.conf` 缺 `[interop]` 段 → `appendWindowsPath` 默认 true，PATH 灌入 50+ 条 `/mnt/c|d|e/...`。后果：WSL 里 `npm` 解析到 **Windows 版**（10.9.7），而 `node` 反而 `No such file or directory`。根治需 `[interop] appendWindowsPath=false` + `wsl --shutdown`（会重启上面 3 个容器）。
2. **`proxy.golang.org` 完全不通**（curl 返回 `000`，非超时非 403）→ 与 macOS 侧 Dockerfile 的 GOPROXY 坑同源，构建必须 `GOPROXY=https://goproxy.cn,direct`。对照：github / registry.npmjs.org / mirrors.aliyun.com / ACR 公网域名 全部 200。
3. **宿主机 Git Bash 直传脚本给 `wsl.exe` 会被拆参数**：`wsl ... bash -lc 'for c in a b; do ...'` 输出的变量全为空。**改用「Write 脚本文件 → `wsl ... bash /mnt/e/.../x.sh`」**，必要时 `tr -d '\r'` 去 CRLF。这条已写进两级记忆。

### 其他观测

- `E:\git_code` 实际内容与旧记录有出入：现为 `001_start` `fanyan_ai_cfg` `new-api-yxw` `ssh_bk1` `ssh_bk1.gz` `study_data` `git开发规范.md` `阿里云国际站菲律宾部署_详细操作指南.md`(+`.bak-v1`) `预发与正式环境区别.md`（旧记录里的 `.qoder/` 已不在）。
