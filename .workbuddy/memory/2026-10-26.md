**方案核心结论（11 条）**：ArgoCD v3 非 HA（~550m/1.15Gi）；单仓 `deploy/gitops/` 不建 ops 仓库；
`push develop` 触发（**绝不用 tag** —— 本仓 `release.yml` 抢 `tags:'*'`，会触发上游三平台二进制构建）；
镜像继续马尼拉 ACR 跨区拉；tag `dev-yyyymmdd-sha7` 但 GitOps 写 **digest**；
`configMapGenerator` 替代 `__CONFIG_CHECKSUM__`；Secret 不进 Git 且 ArgoCD 不声明；
只纳管 3 个 workload + Service + Ingress，**AlbConfig/IngressClass 不纳管**（finalizer 会级联删云上 ALB）；
AppProject destination 限 `newapi-dev`（同集群有 pre/perf）；过渡 `selfHeal/prune` 三档开关。
