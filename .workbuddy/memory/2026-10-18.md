**用户指令**：跑命令前先判当前 OS；Windows 默认先 `wsl` 进 Ubuntu 再执行；macOS 直接本机执行。

**改了什么**
- `.workbuddy/memory/MEMORY.md` → 「## 执行环境（最高优先级 · 2026-10-18 修正）」重写：
  - 判法 `uname -s`：`Darwin` = macOS 直跑；`Linux`(WSL) = 已在 Ubuntu；Windows 原生 shell ⇒ 先起 WSL。

- `.workbuddy/memory/REFERENCE.md` → 把 10-17 写的「macOS 宿主可直接跑 / 不必经 WSL」改为「先判 OS 再选通道」，并补上同一条澄清。
