### ★ 三条发文知识（写命令/操作前必看）

1. **`IfNotPresent` + 复用 tag = 假发布**。同 tag 覆盖推送后，kubelet 认为本地已有该 tag 而不拉新 ⇒ 发布"成功"但内容没变。现 tag 形如 `20260928-26ac63233`（日期+commit）⇒ **必须每次发新 tag**；若真要复用 tag，只能用「重新部署」强制重建。根治：改 `Always` 或用 digest 引用。
2. **控制台改 = drift**。该 deployment 由 `kubectl apply -f` 管理 ⇒ 控制台手改会与源 manifest 分叉，下次任何人 `apply` 旧文件就把改动**静默回滚**（与 10-06 发现的 HPA `averageUtilization` 70 vs 65 drift 同一类病）。⇒ 控制台只作应急/试发，正式发布应改源 manifest 后 apply。
3. **发布零中断已有保障**：`maxUnavailable=0` + PDB 70% + HPA min4 ⇒ 先起新 Pod 就绪再杀旧。Ingress 侧 EndpointSlice 自动同步（10-06 已实测）⇒ 发布不需要动 AlbConfig/Ingress。

### 控制台入口（ACK 新版）
集群 → 工作负载 → 无状态 → ns `new-api` → `new-api-stable` → 右上 `编辑`（表单改镜像 tag / YAML 直改）→ 更新；同页 `重新部署`（= `rollout restart`）、`更多 → 回滚`。
