# 2026-10-25

## newapi.token.yanxuewei.xyz /setup 页面 500 修复（yxl-hsvr0）

**现象**：浏览器打开 `https://newapi.token.yanxuewei.xyz/setup` 渲染 GeneralError 页（大号 500 + 返回/反馈/返回主页）。后端 `docker logs new-api` 无任何 4xx/5xx，`/api/setup` 与 `/api/status` 均 200。

**根因**：宿主宝塔 nginx 全局安全头 snippet
`/www/server/panel/vhost/nginx/snippets/security_headers.conf:12`
的 CSP 含 `require-trusted-types-for 'script'`。TanStack Router 路由 chunk 预加载（`Route.preload` → 动态创建 `<script>` 并赋值 `src`）被 Trusted Types 拦截：

```
TypeError: Failed to set the 'src' property on 'HTMLScriptElement':
This document requires 'TrustedScriptURL' assignment.
  at c.u [as preload] (vendor-tanstack.js)
```

异常冒泡到 `__root.tsx` 的 `errorComponent: GeneralError`，error 无 `response.status` ⇒ 显示 500。前端本身不支持 Trusted Types（未调用 `trustedTypes.createPolicy`），二者不兼容。

**修复**：`cp -a` 备份后 `sed -i "s/ require-trusted-types-for 'script';//"`，`nginx -t` + `nginx -s reload`。CSP 其余指令（`script-src 'self' 'unsafe-inline' 'unsafe-eval'` 等）全部保留。备份：`security_headers.conf.bak.20261025164822`。

**验证**：Chrome headless（`/Applications/Google Chrome 2.app`，playwright-core 直连 executablePath）复测，/setup 正常渲染四步初始化向导，无 console 报错。

**遗留**：该 snippet 被 5+ 站点 include，本次改动全局生效（仅放宽，不建议回滚）。数据库 `users`/`setups`/`options` 全空 ⇒ 系统仍未初始化，需在 /setup 向导里创建管理员。

**同日同步到另两台**：`yxl-svr1`（VM-24-16-opencloudos）、`yxl-asvr0`（iZuf6g3ljksaa10daavd87Z）同一 snippet（均创建于 10-11 22:26/22:28）同样含该指令，采同样手法修复；备份 `security_headers.conf.bak.20261025165549` / `.bak.20261025165550`，`nginx -t` 均通过并 reload。逐 vhost 以 `curl -k -H "Host: <server_name>" https://127.0.0.1/` 复核，`trusted-types` 计数全为 0。三台宝塔机器（yxl-hsvr0 / yxl-svr1 / yxl-asvr0）已一致。

**排查手法备忘**：`playwright-cli` 装不上浏览器时可绕过 CLI，直接用 `@playwright/cli` 自带 `playwright-core` + 本机 Chrome 的 `executablePath` 起 headless 抓 console/pageerror，比装 chromium 快得多。
