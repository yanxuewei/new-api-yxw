## SLS 时间字段精确到 ms（任务 26 追加，两集群 ✅）
- **机制（源码级）**：`__time__` 恒为秒；亚秒存 `__time_ns_part__`。LoongCollector `plugins/processor/gotime/processor_gotime.go` 中 `log.TimeNs` **只在「时间处理器 SetTime=true」且「global.EnableTimestampNanosecond=true」时写入** ⇒ 纯采集不产 ns，必须两件套。前置 LoongCollector ≥1.8.0（实测 logtail-ds = v3.3.3.1-aliyun）。
- **四处"开关带不进去"的坑**：① 老式 `AliyunLogConfig.inputDetail.enable_timestamp_nanosecond` → 控制器剥键（CLI GetConfig 无此键）；② 新 OpenAPI `aliyun sls UpdateConfig`（--body 全量回写）→ 静默剥键；③ python SDK `update_logtail_config`（新 API 语义）→ 同；④ `ClusterAliyunPipelineConfig.spec.config` 顶级同名键 → 剥；**只有 `spec.config.global` 能持久化**。
- **生效清单**：`deploy/sls/clusterpipelineconfig-app-stdout.yaml`（mnl）/ `...-sg.yaml`（sg）——新式 CRD，`spec.project.name` 必填、`spec.config.name` 不许自定义（webhook 拦）。**⚠ 输入插件起初误换为原生 `input_container_stdio`，同日已改回旧版 `service_docker_stdout`（见下节「字段名回归修复」）**。处理器 `processor_gotime`（SourceKey=`_time_`，Go layout `2006-01-02T15:04:05.999999999Z07:00`，DestKey=event_time_ms，**SetTime: true**）。四参数 SourceKey/SourceFormat/DestKey/DestFormat **全必填**（缺则 `ParameterInvalid: DestFormat is missing`）。
- **验收**：mnl `__time_ns_part__=377344812` ↔ `_time_=…15:41:01.377344812+08:00`；sg `453783474` ↔ `…15:43:31.453783474+08:00`，完全吻合 ✅。
- **新坑**：SLS CLI 必须显式 `--region`（查 sg 项目不带会报 `ProjectNotExist` 假错，端点按地域隔离）；`GetLogsV2` 默认返回窗口内**最早** N 条 → 取最新要 `"reverse":true`；`--cli-query` 不支持 `?`。

## SLS 容器元数据字段名回归修复（同日，两集群 ✅）
- **现象**：纳秒上线后，控制台/查询里 `_pod_name_`、`_image_name_`、`_container_ip_` 等列**全空**（仅 content 有值）。
- **根因（iLogtail 2.0「tag 归位」）**：`service_docker_stdout`（旧版 Go 插件）把容器元数据写**普通字段**（裸名 `_pod_name_`）；`input_container_stdio`（新原生插件）一律写 **`__tag__:` 前缀系统标签**。旧版 API（`AliyunLogConfig`）建的配置沿用 1.x 行为=字段；新版 API（pipeline）建的配置默认归位=标签。
- **两条修正**：① `global.UsingOldContentTag: true`（官方"还原 1.x"开关）→ **对原生插件无效**（重启 logtail-ds 后仍 `__tag__`，实测）；② **输入插件改回 `service_docker_stdout`** → ✅ 立即恢复裸字段（`UsingOldContentTag: true` 保留作双保险）。
- **关键结论**：`__time_ns_part__` 与输入插件**无关**（由 global 开关 + `processor_gotime SetTime` 决定）⇒ 用回 `service_docker_stdout` **不牺牲毫秒**。原"老插件不产 ns"系误判。
- **验收**：mnl `_pod_name_=new-api-stable-f6f987798-m6g2m` / ns=946947518；sg `_pod_name_=new-api-ph-standby-5ccf946c69-wt8jp` / ns=490802677（裸字段与 ns 同时保留）。注意 `_node_name_/_node_ip_/_cluster_id_` 一直是 `__tag__:`（新旧一致，非本次回归）。
- **改动**：两清单 inputs 区块改 `service_docker_stdout`（+Header 注释）；报告加「⏱ 追加 2（2026-10-08）」节；新增探针 `deploy/logs/{sls_dump_fields.sh,sls_newest_fields.sh,sls_newest_fields_sg.sh}`。
