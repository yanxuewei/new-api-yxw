### 脚本开发踩坑（都在本会话复现）

1. **zsh 不做变量分词** —— `S="bash ram_user_mgmt.sh"; $S add-group ...` → `command not found: bash ram_user_mgmt.sh`。zsh 把整个字符串当命令名。改直接调用。
2. **`$REGION）` 全角括号被吞进变量名** —— `head1 "RAM 用户列表（region=$REGION）"` 报 `REGION）: unbound variable`。3 处。修法：`${REGION}）`。**这条 MEMORY.md 里早有记录，仍然复现了一次** → 以后写带中文的字符串一律用 `${VAR}`。
3. **`UpdateUser` 的 `--NewUserName` 是必填** —— 只传 `--NewDisplayName` 报 `missing required parameter(s): --NewUserName`。改显示名要传同名 `--NewUserName "$u"`。
4. **`jq_get` 对 JSON 列表返回 Python repr** —— `[{'UpdateDate': ...}]` 被 `for u in $users` 按空格分词 → 用户名字段全乱。修：列表按行输出、dict 走 `json.dumps`。
5. **判定「有/无」不能用子串匹配** —— `GetLoginProfile` / `GetUserMFAInfo` 的错误响应里含实体名（`EntityNotExist.User.LoginProfile`）→ `grep 'MFADevice'` 误判「已绑定」。改为取字段值判空。
6. **`say()` 不解释 ANSI 转义**（`printf '%s\n'`）→ `say "\033[31m..."` 原样打印。带颜色的行改用 `printf`。
7. **Python 生成 HTML 时 CSS 里的 `%` 与 `%s` 格式化冲突** → `ValueError: unsupported format character ';'`。改用字符串拼接。
