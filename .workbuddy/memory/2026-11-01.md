- **不用 `kubectl diff -f` 的原因**：有两类稳定噪声——`metadata.generation`（ArgoCD 写 status 推高计数）与 Service ignoreDifferences 的 `group:""` 归一化（补进文件也消不掉，已做对照实验）。改为两侧各自 `kubectl create --dry-run=client -o json | jq -S <归一化>`，只比 spec 语义字段：project / source / destination / syncPolicy(automated、syncOptions 排序、retry) / revisionHistoryLimit / ignoreDifferences(补 group 后排序) / labels / finalizers。
- **实测（节点内）**：`-f`、`-a` 两模式均 `[✓] 一致` exit 0；负向用例（prune false→true）精确打印 `"prune": true` vs `false` 并 exit 1。
- 本机跑法：`deploy/lib/ack_remote_jkt_dev.sh` + `deploy/logs/retry_run.sh <body> <node> 6`。
- ⚠ **云助手命令体上限实测**：body 7903 字节 → 包装后 15041（wrapper 内联≈×2）⇒ 单 body ≤7.5KB；超了拆两步（先落文件再执行）。

## WSL 出网间歇性全断（2026-11-01 多次复现）

- 现象：`curl` 访问 aliyun/github 全 000 超时，但 `ping 223.5.5.5` 通、`https://www.baidu.com` 200 ⇒ **国内通、国际链路抖**；`aliyun cs` 报 `dial tcp ...: i/o timeout`，ack_remote 连番失败。
- 处置：① `wsl --shutdown` 有时恢复、有时无效（需再等）；② 用 `deploy/logs/retry_run.sh`（20s×N 重试）；③ ❌ 不要在同一条 `wsl bash -c` 里用变量拼输出（变量被吞，输出会被当命令执行）。
