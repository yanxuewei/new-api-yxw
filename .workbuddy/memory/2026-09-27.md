## 12:1x GTM 池间语义澄清（回答"GTM 平时是否给新加坡分摊流量"）

**答：不分摊。** 方案口径 = 主备地址池（failover），不是多主池分摊。
方案内证：xlsx `sheet2#16` / `sheet3#9`「主地址池 = 马尼拉 ALB；备地址池 = 新加坡 ALB」；指南 `:2440` 坑5「备站只接 GTM 备地址池，**常态零流量**」；指南 `:234`「虚线那条路径常态**不承载流量**」；指南 `:3787`/`:4186` 备池最终决策「**常驻但权重 0**」；指南 `:3812`「SG→MNL RDS 探测失败率 >10% → **自动把备池权重置 0**，禁止切换」。

**官方语义（2026-09-27 查证 `help.aliyun.com/zh/dns/principles` + `/document_detail/2782188.html` + `/zh/dns/gtm2-access-policy`）**：
- 「访问策略」= 策略类型（按地域 / 按延迟）+ **主地址池集合 / 备地址池集合** + **生效地址池集合切换策略**，三者正交
- 主池健康 → **优先返回主池 IP**；主池不可用 → 自动切备池
- 「基于访问延时的访问策略」**仅旗舰版**，官方自警「延时调度库精准性与更新时效性问题，有可能出现个别地域延时无法做到最优」+「可能用户请求会集中调度到某个IP上」
- 触发条件含「**地址池集合可用 IP 最小数量阈值**」：健康 IP 数 < 阈值 → 整池判不可用 → 切备池
- 池内「负载均衡策略」= 返回全部地址（默认，**平均分配**）/ 按权重

**核心口径**：把跨区切换判定点从 GTM（DNS 层，45–60s 判定 + 不可控传播）下沉到 **DCDN 回源层**（主动四层探测 2.5s × 3 = 7.5s 判定，客户端连 CDN 边缘 IP 不变 → 传播 0）→ 端到端 RTO **10–20s**（对比现状乐观 105s / 中位 6.8min / 长尾 31.8min）。净增 **≈ +74 USD/月**（下行流量 60 + 动态请求数 14.4）。

**官方机制（`configure-an-origin-server`，2026-09-10 更新）**：源站支持直接填 ALB 实例域名；主备优先级 0–127（默认主 20 / 备 30，非默认须工单）；**主动四层 TCP**，每 2.5s 探一次、连续 3 次失败判不可用；恢复每 5s 重探；回源超时 TCP 建连 10s / 写 30s / 读 30s，全链路最长 150s；默认透传 `Ali-Cdn-Real-Ip` 等；动态资源默认「性能优先回源」。

**三个硬约束**（不解决方案空转）：① 四层探测对应用层故障免疫（Pod 全挂时 ALB 返 5xx，DCDN 不摘源站）→ 工单开七层屏蔽 或 叠加 GTM；② 动态资源性能优先回源会绕过主备优先级；③ 回源读超时默认 30s → SSE 截断。另：**DCDN 不支持内网源站** → 两 ALB 必须有公网地址。

**拓扑三选一**：纯主备（仅兜 ALB 不可达）/ CDN>GTM 联动（~47s）/ **双层叠加（推荐，全兜）**。

**实施顺序**：先做零成本项 GTM `Ttl` 60 → **1s**（旗舰版支持，把可控路径 105s → 46s），再提 2 个工单，再采 2 周基线，最后才动生产 DNS。

**遗留**：DCDN 对 SSE 的缓冲/首字节行为无官方文档（须实测）；DCDN 对 5xx 回源重试可能触发 POST 重复计费；`§8.2`「60s」与 `§8.4`「≤5 min」口径打架、`§7.4.4` 缺 HPA vs 指南「HPA 2-24」矛盾 —— 4 处文档冲突待统一。
